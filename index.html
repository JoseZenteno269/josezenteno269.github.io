Quién soy

// zunox-3d · en producción

ZUNOX 3D, el sistema de un negocio de impresión 3D

En producción Lo hicimos entre tres, como TechIntoBios.

  • Para el dueño

    Carga clientes y pedidos, maneja el catálogo y cambia el estado de cada pedido.

  • Para el cliente

    Mira el catálogo, consulta por WhatsApp y sigue su pedido con un link propio.

  • Por dentro

    API en C# con .NET 10, ADO.NET sobre PostgreSQL, sesión con JWT y mails con Resend.

  • C#
  • .NET 10
  • ADO.NET
  • PostgreSQL
  • JWT
  • Docker
Ver el sitio Ver código

Seguimiento del pedido

Cada pedido tiene un link único con el estado, el detalle y el total.

Aviso por mail

Cuando el negocio cambia el estado, el cliente recibe un mail automático.

Panel de seguimiento

El negocio encuentra los pedidos de un cliente, deja una observación y edita sus datos.
